# Dashboard de Cadastro e Gestão 📊

Interface administrativa robusta focada em segurança de dados e experiência do usuário (UX). Este projeto simula um ambiente real de gestão corporativa.

## 🚀 Tecnologias
- **React.js** com **TypeScript** para tipagem estrita e segurança.
- **Material UI** para componentes de interface consistentes.
- **Axios** com configurações customizadas para consumo de API.
- **Yup** para validação rigorosa de formulários.

## 🛠️ Funcionalidades
- CRUD completo com dados mockados.
- Validação de inputs em tempo real.
- Layout responsivo para diferentes resoluções.

## 🧠 Desafios Técnicos
Como ex-analista de sistemas, foquei em garantir que a arquitetura dos dados fosse escalável. O maior desafio foi implementar a validação complexa com Yup, garantindo que a interface respondesse de forma amigável aos erros de preenchimento.

## ⚙️ Como rodar o projeto localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/Anna-Madeira/project.git](https://github.com/Anna-Madeira/project.git)
2. **Acesse á pasta do projeto**
   cd project

   3. **Instale as dependências**
  npm install
    # ou
  yarn install

  4. **Inicie o servidor de desenvolvimento**
     npm run dev
      # ou
      npm start

     5. **Abra http://localhost:3000 (ou a porta indicada no terminal) para ver o resultado.**
